## 關鍵事實(推翻 Phase 0 假設)

- **沒有獨立「支付賽道」**。只有兩個賽道。
- 獎池 **$60,000 USDC**。
- 截止:**2026-09-08 23:59 UTC**(從 9/3 起只剩 ~5 天)。
- 提交方式是 **X(Twitter)公開投稿**,不是傳統 hackathon 平台。

## 兩條賽道

| | 賽道 A | 賽道 B |
|---|---|---|
| 名稱 | 使用 Agent OS 構建 AI 代理 | 連接您的 MCP 並進行交易 |
| 獎金 | **20K USDC** | **40K USDC** |
| 提交材料 | 回覆/引用轉發:**影片/demo + GitHub**(如適用) | 公告只明確寫了賽道 A 的提交格式;B 可能更偏「真的連上 MCP 並成交」 |
| 核心技術 | Agent OS 全家桶(MCP / Skills / Pay x402 / Wallet / APIs) | **必須接 Binance MCP 並完成交易** |

## 如何參賽(官方清單)

1. 關注 [@Binance](https://x.com/Binance) 並轉發官方帖
2. 回覆或引用轉發提交內容(賽道 A:影片/demo + GitHub)
3. 完成調查:[app.binance.com 問卷](https://app.binance.com/uni-qr/user-survey/2913aa200aac462c89a737779393f3d4)
4. 技術棧頁:[binance.com/en/agent-os](https://www.binance.com/en/agent-os)
